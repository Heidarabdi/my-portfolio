# Structure homepage concept

Wonder file: Potoo. Artboards: Heidar Structure Homepage and Structure Mobile Hero. The mobile hero collapses the identity rail into a compact header and stacks the blue introduction above the architectural image.

A reimagining of the current portfolio inspired by the user's Ronan Pike reference: https://www.behance.net/gallery/255060365/Ronan-Pike-Full-Stack-Developer-Portfolio-Website/modules/1485050497

The Behance link was unavailable through web browsing, so the supplied screenshots guided the composition: a persistent identity rail, strong editorial grid, architecture imagery, condensed display typography, and alternating color sections. The new palette adds ultramarine, orange, yellow, warm paper, and pale color accents. Body labels use IBM Plex Mono; display type uses Barlow Condensed.

Uses actual portfolio project content, technical skills, journal articles, and client quotations. The HA identity tile replaces the reference's portrait. No portrait of Heidar was available. Reference experience and client counters were replaced with factual professional details. The architectural imagery and project covers are visual studies, not photographs of project buildings or screenshots of applications.

The contact form is a canvas design. No frontend or deployment changes were made.

## Image generation

Asset: `structure-architecture-v1.png`. Generated with the built-in image generation tool.

Final prompt:

Use case: stylized-concept. Asset type: architectural hero image for a colorful editorial software developer portfolio. A dramatic low-angle architectural photograph of a compact brutalist concrete structure made of three intersecting geometric volumes and one deep rectangular opening. Raw pale-grey concrete, visible subtle aggregate texture, razor-sharp structural edges, powerful diagonal lines, hard midday shadows, museum-quality architectural photography. Composition is an original graphic collage: black-and-white building occupies the lower two-thirds of the frame; a huge perfectly flat vivid safety-orange semicircle, like a rising sun, sits behind the building against a warm light paper sky (#F1EFE6). A small solid ultramarine-blue rectangular plane in the upper right creates a decisive geometric counterpoint, occupying less than 8% of the image. Controlled and precise, modern Swiss editorial art direction, energetic but not cluttered. Wide 5:4 image, full bleed, crop boldly at bottom and right; no border or frame. One continuous scene, no collage panels. No text, no people, no logos, no watermarks, no interface, no screens, no glowing orbs, no neon, no gradients. The structure should feel sculptural and expertly engineered, a visual metaphor for thoughtful software systems rather than an actual project building.
