# Signal homepage concept

Designed in Wonder: Potoo / Heidar Signal Homepage, with Signal Mobile Hero alongside it. This is a separate design direction from the reference-based homepage.

Palette: black, warm white, and pink. Typography: Sora with IBM Plex Mono labels. The hero uses the generated `signal-halftone-lens-v1.png` asset, with editable typography and controls layered separately in Wonder.

The lens is a generated still, not a live WebGL shader. The project architecture study is a diagram, not an application screenshot. Source content comes from the existing portfolio: Heidar's role, ML Integration Platform, SNWO Official Portal, Sentiment Analysis Tool, capabilities, and Setsom testimonial.

## Intended motion for implementation

A slow rotation and subtle pointer response would suit the dimensional lens. A future real-time implementation could render a toroidal surface with halftone or ASCII sampling, retaining the still artwork for reduced motion and unsupported devices. No live shader or website changes are included in this design task.

Technical references reviewed: https://shaders.com/docs/components/halftone and https://shaders.com/docs/components/ascii

Art direction: high-end contemporary generative typography exhibition, dithered 3D shader still, sharply sampled stipple, beautiful controlled aliasing, not a smooth glossy metallic object.
