# Glass Studio portfolio concept

Wonder file: Potoo. Artboards: Heidar Glass Studio Homepage and Glass Studio Mobile Hero.

The design follows the user's supplied Jenny portfolio reference with a character-centered hero, coral circle, floating frosted-glass details, layered service previews, project experience, selected work, client quotations, a journal, and a contact invitation. It keeps a light theme with warm white, coral, peach, and ice-blue surfaces. Typography uses Outfit.

The character is a generated representative illustration, not a likeness or photograph of Heidar. The source reference's person was not reused. The transparent PNG remains separate from editable circles, typography, cards, and buttons in Wonder.

Project experience is based on the portfolio's project/client records and years. It is not presented as a verified employment timeline. The design uses existing project names, actual client quotes, and journal subjects. Reference achievement counters, ratings, and client totals were not copied. Portfolio interface studies are design concepts, not screenshots of actual applications.

This is a static canvas design. No website code, contact backend, deployment, or repository history was changed.
