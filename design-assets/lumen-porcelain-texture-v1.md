# Lumen light homepage concept

Wonder file: Potoo. Main artboard: Heidar Lumen Homepage. Mobile companion: Lumen Mobile Hero.

A light portfolio direction based on the user's four supplied references: tactile embossed pixels, luminous texture fields, subtle ASCII/dot patterns, and fluted glass. Uses a near-white porcelain ground, mint and sky-blue reflections, a restrained peach accent, dark green text, and green primary actions. Typography combines Manrope with Instrument Serif; small technical labels use IBM Plex Mono.

The hero and contact section use the generated porcelain-wave texture. The capabilities section uses a native dot pattern. The testimonial uses native glass-rib layers. Page copy, project names, disciplines, client quotation, and journal subjects come from the existing portfolio. Project interface studies are design concepts, not screenshots of actual applications.

This is a static Wonder design. No website code, shader runtime, deployment, or contact delivery configuration was changed.
